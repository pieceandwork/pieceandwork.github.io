## 📖 О проекте

Этот сайт - одностраничное приложение (SPA), которое заменяет контент без перезагрузки страницы. Написан без использования фреймворков и сборщиков, только "ванильный" HTML, CSS и JS.

**Основные возможности:**
- 📱 Адаптивный дизайн (работает на телефонах и ПК)
- 🎨 Тёмная тема с оранжево-желтыми акцентами
- ⚡ Плавные анимации переходов и наведения
- 🗂️ Удобная навигация по разделам: "Обо мне", "Мои работы", "Сертификаты"

## 🛠 Стек технологий

| Технология | Описание |
| :--- | :--- |
| **HTML5** | Семантическая разметка |
| **CSS3** | Стили, анимации, Flexbox, Grid, адаптивность |
| **JavaScript (ES6)** | Логика переключения разделов, DOM-манипуляции |
